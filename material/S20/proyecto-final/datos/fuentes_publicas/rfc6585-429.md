El código de estado 429 Too Many Requests indica que el usuario ha enviado demasiadas peticiones en un periodo de tiempo determinado; es el código previsto para la limitación de tasa (rate limiting).

La respuesta 429 debería incluir una representación que explique la condición, y puede incluir la cabecera Retry-After para indicar cuánto tiempo hay que esperar antes de hacer una nueva petición.

La especificación no define cómo identifica el servidor al usuario ni cómo cuenta las peticiones: el límite puede aplicarse por recurso, por servidor o por conjunto de servidores, y por usuario autenticado o por otro criterio.

Las respuestas con código 429 no deben almacenarse en una caché.
