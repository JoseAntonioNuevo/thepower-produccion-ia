# Sesión de preparación de base común y S16

Se creó el repositorio local independiente `4-produccion-ia`, con FastAPI, contratos de soporte heredados de S7/S8, modo demo explícito y adaptador Anthropic. Se prepararon Docker, dos plantillas CloudFormation, operaciones con destino verificado, cálculo de costes y el paquete docente S16. Se mantuvieron los otros proyectos sin cambios de código.

Razón: cubrir el temario y el ejercicio completo de S16 y facilitar la reutilización posterior en S17–S20 sin confundir una demo con una integración real.

Verificación: 24 tests, lint/formato, cfn-lint, Docker amd64 no root/read-only, HTTP local con límites de CPU/memoria, tarifas públicas y cálculo, 20 diapositivas con notas/PDF, guion de 90 minutos y guía del alumno, archivos de distribución extraídos y probados. Los límites y recibos están en `material/S16/verificacion.md`.

Aprendizajes reutilizables: identificar ejecución y versión en cada respuesta; separar salud e inferencia; conservar consumo desconocido; verificar cuenta/digest antes de operar; mantener recibos históricos; probar el paquete exacto del alumno; contrastar cobertura docente y ejecución cloud como evidencias distintas.

Pendiente: cuenta/permisos/presupuesto y ensayo AWS con inferencia real, cleanup/readback y ensayo oral. No se hizo commit, push ni despliegue.

OpenViking: el selector no devuelve una cuenta para el repositorio. No se creó ni se utilizó otro tenant. Esta nota local conserva la entrega pendiente, sin credenciales ni datos de alumnos.
